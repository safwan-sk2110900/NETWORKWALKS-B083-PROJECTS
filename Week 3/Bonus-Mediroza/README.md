## 🟪 WEB APPLICATION PENETRATION TEST — MEDIROZA GENERAL HOSPITAL

---

### 📖 Overview

This repository contains a **web application penetration testing assessment** performed against **Mediroza General Hospital** as part of the **Networkwalks B083 Cybersecurity Internship — Week 3 Bonus Project**.

The assessment followed a **black-box penetration testing** approach. The goal was to identify security weaknesses in the target web application, confirm their real-world impact through controlled and authorized exploitation, and document clear, practical remediation steps.

> ⚠️ **Disclaimer:** This project was conducted in a controlled environment with written authorisation. The techniques and testing methods described here must only be used against systems where explicit permission has been provided by the owner.

## 🧭 Methodology

The assessment was carried out across four phases:

1. **Reconnaissance** — Gathering information about the target using publicly available information and web-based tools.
2. **Vulnerability Identification** — Testing application behaviour, authentication, and input handling.
3. **Exploitation** — Performing controlled exploitation to confirm the impact of identified vulnerabilities.
4. **Documentation** — Recording findings, evidence, impact, and remediation recommendations.
